# Detis Engine

Detis is a lightweight engine for 3D single-player PC games. Drop in assets, edit worlds, script in Lua, hit Play. Editor and game are the same executable.

Scope, platforms, license, and pricing: [FAQ](faq.md).

## How you work

- One engine copy is one game. No launcher and no project wizard.
- Worlds, materials, scripts, and shaders are plain text.
- Meshes are glTF / GLB. Textures are DDS or KTX. No import step.
- Gameplay is Lua. After you change files on disk, reload scripts and assets from the editor.
- Target: 64-bit Windows and Linux with a dedicated GPU. Hand-authored levels, not streamed open worlds.
