# Editor

The editor and your game run in the same executable. If you are new, start with [Editor overview](editor_overview.md) (toolbars, Play, save, inspectors).

This section holds deeper editor reference pages. More guides will be added over time.

| Page | When to open it |
|------|-----------------|
| [Editor overview](editor_overview.md) | Toolbars, menus, Play, save, prefabs, and day-one shortcuts. |
| [Viewport navigation](editor_viewport_navigation.md) | Spectator camera: fly, pan, orbit, orthographic zoom, focus shortcuts. |
| [Engine Settings](editor_engine_settings.md) | **File → Settings**: theme, display, graphics quality, shadows, volumes, external tools. Use this if the editor or Play mode feels slow or too loud. |
