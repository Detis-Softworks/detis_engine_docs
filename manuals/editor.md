# Editor

The editor and your game run in the same executable. If you are new, start with [Editor overview](../getting_started/editor_overview.md) in **Getting started** (toolbars, Play, save, inspectors).

This section holds deeper editor reference pages. More guides will be added over time.

| Page | When to open it |
|------|-----------------|
| [Engine Settings](editor_engine_settings.md) | **File → Settings**: theme, display, graphics quality, shadows, volumes, external tools. Use this if the editor or Play mode feels slow or too loud. |
